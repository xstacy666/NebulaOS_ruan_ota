# Nebula OS (ColorOS 17) Official OTA Endpoint

Official Over-The-Air (OTA) update repository for **Redmi Pad Pro / 5G** (`ruan` / `dizi`).

- **OS**: Nebula OS (Powered by ColorOS 17 / Android 17)
- **Maintainer**: Øpium (`xstacy666`) | Team Nebula
- **Recovery Engine**: OrangeFox Recovery / TWRP

## Architecture
- Manifest: `ota.json` (Served live via GitHub raw CDN)
- Packages: Hosted on Google Drive / Releases
- Recovery Handover: Direct `/data/cache/recovery/openrecoveryscript` execution
